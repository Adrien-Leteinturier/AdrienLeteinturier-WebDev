# Kit d’acquisition — 90 jours

## Convention UTM

Utiliser ce format pour les liens partagés :

`/?utm_source=linkedin&utm_medium=organic&utm_campaign=pack-vitrine`

Variantes prévues : `linkedin`, `x`, `facebook`, `partner`.

## Quatre publications LinkedIn

### Semaine 1 — Le site n’est pas une brochure

Un bon site de PME doit répondre rapidement à trois questions :

- Que faites-vous ?
- Pour qui ?
- Quelle est la prochaine étape ?

Si le visiteur doit chercher ces réponses, le problème n’est pas forcément
votre activité. C’est souvent le message, la structure ou le parcours.

Je conçois des sites vitrines clairs et utiles pour les entreprises de services.

→ `/?utm_source=linkedin&utm_medium=organic&utm_campaign=pack-vitrine`

### Semaine 2 — Trois signaux d’une refonte nécessaire

Votre site mérite probablement une refonte si :

1. il est difficile à utiliser sur mobile ;
2. vos services sont décrits comme une liste, sans bénéfice concret ;
3. aucun appel à l’action n’indique quoi faire ensuite.

Une refonte efficace commence par les priorités commerciales, pas par les
animations.

### Semaine 3 — Coulisses

Avant d’écrire une ligne de code, je cherche à comprendre le quotidien de
l’entreprise : demandes reçues, outils utilisés, informations répétées et
points de friction.

Le meilleur développement web n’ajoute pas de complexité. Il en retire.

### Semaine 4 — Offre vitrine

Pour une PME de services, un site vitrine doit être :

- crédible au premier regard ;
- compréhensible sans jargon ;
- rapide à consulter sur mobile ;
- simple à faire évoluer ;
- conçu pour recevoir les bonnes demandes.

J’ai structuré une offre de départ à partir de 1 500 €, selon le périmètre.

## Message de prospection personnalisé

Bonjour [Prénom],

Je suis développeur web freelance et j’ai regardé le site de [Entreprise].
J’ai remarqué [observation précise et vérifiable]. Cela peut rendre plus
difficile [conséquence pour un visiteur ou un prospect].

Je peux vous envoyer gratuitement trois pistes concrètes d’amélioration, sans
engagement. Si le sujet est déjà traité, ignorez simplement ce message.

Bonne journée,
Adrien

## Règles de suivi

- 5 prospects ciblés par semaine maximum.
- Une seule relance après 5 à 7 jours.
- Aucun message identique envoyé en volume.
- Noter dans un tableau : entreprise, URL, observation, date, réponse, étape
  suivante et source UTM.
